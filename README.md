# REPUBLIC — безопасная версия

Проект: простой CMS новостного сайта с улучшенной безопасностью и стабильностью.

Ключевые изменения, которые я внёс:
- Сессии и посты теперь хранятся в SQLite (папка data/) вместо файлов posts.json
- Секреты вынесены в переменные окружения через dotenv (.env.example)
- Добавлены заголовки безопасности (helmet), ограничение попыток входа (rate-limit)
- Добавлена CSRF-защита (csurf) для state-changing запросов
- Серверная валидация (express-validator) и очистка контента (sanitize-html)
- Клиент теперь отправляет куки (credentials: 'include') и использует CSRF-токен

Запуск локально:
1) Скопируйте .env.example в .env и заполните переменные.
2) Установите зависимости: npm install
3) Запустите сервер: npm start
4) Откройте http://localhost:3000

Пример .env (файл .env не должен храниться в репозитории):

ADMIN_PASSWORD=change_me
SESSION_SECRET=change_me_too
NODE_ENV=development
PORT=3000

Если потребуется использовать Redis для сессий или разрешать HTML в постах — скажите, и я адаптирую проект.
